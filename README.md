## What it does

Answer a structured questionnaire across strategy, data, talent, infrastructure and governance — get a scored readiness report with a prioritized AI adoption roadmap.

## Key features

- **Weighted scoring** across 5 AI maturity dimensions.
- **Gap analysis** — see exactly where you fall behind peers.
- **Adoption roadmap** — sequenced next steps with effort estimates.
- **Shareable report** — export for leadership buy-in.
